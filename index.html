Stiven Gjekaj

6 apps for old iPhones on a jailbreak.

Add to Cydia

Or add this source in Cydia, Sileo, or Zebra:

https://stiven-gjekaj.github.io/cydia/

With APT, put this line in a file in /etc/apt/sources.list.d/:

deb https://stiven-gjekaj.github.io/cydia/ ./

On iOS 6, Cydia cannot read this source. GitHub Pages accepts only TLS 1.2, and the APT of iOS 6 stops at TLS 1.0. On iOS 6, download the .deb below and install it with dpkg -i, or with an app that installs a .deb file. The source works with iOS 7 and later.
